---
title: "Read Only"
weight: 1
---

Read-only properties provide insights into the quadrille's current state and cannot be directly modified:

- **[mouseRow](mouse_row/):** The row index of the cell currently under the mouse pointer.
- **[mouseCol](mouse_col/):** The column index of the cell currently under the mouse pointer.
- **[size](size/):** The total number of cells in the quadrille.
- **[order](order/):** The number of non-empty cells in the quadrille.
- **[span](span/):** The smallest axis-aligned rectangle that contains all filled cells in the quadrille.
