title: "Read Write"
weight: 2
---

Read/write properties can be both accessed and modified, allowing dynamic control over the quadrille's dimensions and content:
- **[width](width/):** The number of columns in the quadrille.
- **[height](height/):** The number of rows in the quadrille.
- **[memory2D](memory_2d/):** A 2D array that represents the content of each cell.
