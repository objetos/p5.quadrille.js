title: "isFunction(row, col)"
weight: 12
symbol: isFunction
---

Returns `true` if the cell found at `(row, col)` is a function and `false` otherwise.

## Syntax

> `isFunction(row, col)`

## Parameters

| Param | Description                                                                       |
|-------|-----------------------------------------------------------------------------------|
| `row` | Number: row index of the cell to be read `∈` [[0..height]](../../../properties/read_write/height/)  |
| `col` | Number: column index of the cell to be read `∈` [[0..width]](../../../properties/read_write/width/) |

> **Note**
>
> Also available as the static method `Quadrille.isFunction(value)`, which takes a `value` instead of a cell position.
