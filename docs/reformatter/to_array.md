Returns a [row-major order](https://en.wikipedia.org/wiki/Row-_and_column-major_order) array of the quadrille cells (refer to [createQuadrille](../../p5_functions/create_quadrille/) for all the possible cell contents). The resulting array has [width](../../properties/read_write/width/) `*` [height](../../properties/read_write/height/) entries, with empty cells as `null`.

## Syntax

> `toArray()`
