Generates a string in Forsyth–Edwards Notation ([FEN](https://en.wikipedia.org/wiki/Forsyth%E2%80%93Edwards_Notation)) representing the current position of the chess board — the inverse of [createQuadrille(FEN)](../../p5_functions/create_quadrille/create_quadrille_FEN/).

## Syntax

> `toFEN()`
