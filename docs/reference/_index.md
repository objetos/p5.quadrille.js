Two lists sit behind the editable examples on this site: the surface **this library adds**, and the surface it **leans on** — p5.js, and the JavaScript the sketches are written in.

Both are derived from the snippets at build time, so neither can list a name the examples do not use, and the number beside each name is how many examples reach for it. Read them as the answer to "what else is this sketch assuming I know?" — the p5.quadrille list doubles as the shortest tour of the library the examples actually need.

- **[The p5.quadrille surface](quadrille_surface/)** — the library's own names, by teaching area, ranked by use.
- **[The host: p5.js and JavaScript](host/)** — the p5 names and the JavaScript the sketches call, with a line each on what they are used for.
