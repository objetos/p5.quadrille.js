The library's own names, grouped by teaching area as the API pages are, and ordered by how many examples reach for them. `createQuadrille`, `drawQuadrille` and `Quadrille.cellLength` come first, and the surface a sketch grows into follows; each name links to the page that documents it.

Only a provable call is here: `Quadrille.name`, the two p5 functions the addon registers, or a member call on a variable the same snippet made with `createQuadrille`. A name reached through a receiver of unknown type is left out rather than guessed, so a page's list can be incomplete but never wrong.
